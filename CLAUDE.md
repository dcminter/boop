# Agent instructions

The contents of ./design/design.md are authoritative and it must not be edited without explicit user permission.

Eschew adjectives. Be terse. Do not praise the user.

Thorough tests cases are encouraged.

Use of (and as necessary installation of) native Debian tooling is preferred over ad hoc scripting. Avoid writing bash, python, etc. when you could instead use ripgrep, jq, sed, and similar text processing tools. You have permission to install new tools whenever needed.

Do not commit or push anything yourself. The user will take care of this on their own initiative.
